## 0. Что понадобится

- ПК с Windows 10/11 (64-бит), **8+ ГБ оперативки** (лучше 16), **~12 ГБ** свободного места.
- [TLauncher](https://tlauncher.org) — официальный сайт, устанавливается за минуту.
- Наш готовый архив: **[TFG-Modern-0.13.17-TLauncher.zip (705 МБ)](https://github.com/Illusivecup/terrafirmagreg_modern_ru/releases/download/client-0.13.17/TFG-Modern-0.13.17-TLauncher.zip)** — внутри уже ВСЁ: 268 модов, конфиги, шейдеры, 11 ресурспаков, русский язык.

## 1. Шаг 1 — TLauncher и Forge (один раз)

1. Установи и запусти TLauncher.
2. Внизу окна, в списке версий, выбери **`1.20.1-forge-47.4.13`** (если в списке нет — ближайший `1.20.1-forge-47.4.x`). Нажми **«Установить»** и дождись окончания.
3. Запусти игру этой версией **один раз**, дойди до главного меню и закрой игру — создадутся нужные папки.
4. В поле ника введи свой будущий игровой ник (лучше латиницей) и запомни его точь-в-точь — он понадобится для вайтлиста.

## 2. Шаг 2 — скачай архив сборки

Скачай **[TFG-Modern-0.13.17-TLauncher.zip](https://github.com/Illusivecup/terrafirmagreg_modern_ru/releases/download/client-0.13.17/TFG-Modern-0.13.17-TLauncher.zip)** (705 МБ). Внутри архива — вся сборка целиком:

- папки `mods`, `config`, `defaultconfigs`, `kubejs`, `resourcepacks`, `shaderpacks`, `tacz`;
- `options.txt` (русский язык), `servers.dat` (сервер уже в списке);
- `ПРОЧТИ_МЕНЯ.txt` — короткая памятка (дублирует эту инструкцию).

> Остальные файлы релиза (`multimc`, `modrinth`, `curseforge`) для TLauncher **не нужны** — они для других лаунчеров.
>
> **Обязательно накати поверх патч v2.1:** [TFG-RU-v2.1-Patch.zip](https://github.com/Illusivecup/terrafirmagreg_modern_ru/releases/download/client-0.13.17/TFG-RU-v2.1-Patch.zip) (0,35 МБ) — распакуй в `.minecraft` с заменой после распаковки основного архива. Он переводит справочник до конца и расставляет клавиши без конфликтов.

## 3. Шаг 3 — распаковка (2 минуты)

1. Открой скачанный архив и выдели в нём **всё** (Ctrl+A).
2. Нажми **Win+R**, введи `%appdata%\.minecraft`, нажми Enter — откроется папка игры (или в TLauncher — кнопка «Папка» внизу справа).
3. Перетащи выделенное из архива **внутрь открытой папки `.minecraft`** и согласись на **замену** (если Windows спросит — «Заменить файлы в папке назначения»).
4. Готово. Моды, конфиги, шейдеры и русский язык уже внутри.

> Важно: копировать нужно СОДЕРЖИМОЕ архива внутрь `.minecraft`, а не саму папку целиком. После копирования прямо в `.minecraft` должны лежать папки `mods`, `config`, `kubejs` и др.
> Старые миры и настройки не пострадают: заменяется только то, что совпадает с новой сборкой.

## 4. Шаг 4 — выдели память

В TLauncher: **«Настройки» → вкладка «Дополнительно» → поле «Память»**:

- у тебя 8 ГБ ОЗУ → поставь **6144 МБ**;
- у тебя 16 ГБ ОЗУ и больше → поставь **8192 МБ**.

Больше 8 ГБ ставить **не нужно** — будет только хуже.

## 5. Шаг 5 — вход на сервер

1. В TLauncher выбери версию `1.20.1-forge-47.4.13`, введи ник, жми «Войти в игру».
2. **Первый запуск долгий (5–10 минут)** — грузятся 268 модов. Чёрное окно и «не отвечает» в начале — это нормально, жди.
3. **Отправь админу свой ник точно-точно** — он добавит тебя командой `whitelist add Ник`. Без вайтлиста сервер не пустит.
4. Сервер **уже добавлен** в списке: «TFG-Modern 0.13.17» → `155.212.219.50:25565`. Если его нет в списке: «Сетевая игра» → «Добавить сервер» → вставь адрес → «Готово» → двойной клик по серверу.

## 5.5. Телепорты и смерть (уже включено на сервере)

| Команда | Что делает |
|---|---|
| `/sethome <имя>` | поставить точку дома |
| `/home <имя>` | вернуться домой |
| `/delhome <имя>` | удалить точку |
| `/back` | вернуться на место смерти/телепорта |
| `/tpa <ник>` | запрос телепорта к игроку (он подтвердит `/tpaccept`) |
| `/rtp` | случайная точка в дикой природе |
| `/spawn` | на спавн сервера |

**Вещи после смерти не выпадают** — инвентарь сохраняется (keepInventory).

## 8. Частые проблемы

- **«Не пускает на сервер»** — ник не в вайтлисте. Напиши админу ровно тот ник, под которым входишь (регистр важен).
- **«Несовпадение модов» при входе** — скопировал не всё. Повтори Шаг 3 внимательно: в `%appdata%\.minecraft` должны появиться папки `mods`, `config`, `kubejs` и др. из архива.
- **Вылет с «Out of memory»** — подними память (Шаг 4).
- **Долго висит чёрный экран** — первый запуск грузит 268 модов, жди 5–10 минут.
- **Хочу добавить свой мод** — нельзя: сервер требует точное совпадение списка модов.
- **Нет Forge 47.4.13 в списке версий** — ищи именно `1.20.1-forge-47.4.13`; если отсутствует, возьми ближайший `47.4.x` и сообщи админу.
- **Мир грузится вечность после входа** — первые минуты прогружаются чанки TFC, через 5–10 минут станет плавно.
- **«Invalid session» / «Неверный токен»** — появляться не должно: сервер специально работает в offline-режиме под TLauncher. Просто перезапусти игру.
- **Сменил ник в TLauncher** — для сервера это новый игрок: сначала скажи админу новый ник, потом заходи.
