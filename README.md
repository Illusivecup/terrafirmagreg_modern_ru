# Установка TerraFirmaGreg Modern для друзей — только TLauncher

Инструкция для игроков: играем через **TLauncher** без лицензии. Сервер работает в offline-режиме с вайтлистом, поэтому главное правило — **твой ник должен быть у админа в вайтлисте**.

**Версии (все должны совпадать точь-в-точь):**

| Что | Версия |
|---|---|
| Сборка | **TerraFirmaGreg Modern 0.13.17** |
| Minecraft | **1.20.1** |
| Forge | **47.4.13** |
| Java | **17** — ставится самим TLauncher, качать не надо |
| Память на клиент | **6–8 ГБ** |

---

## 0. Что понадобится

- ПК с Windows 10/11 (64-бит), **8+ ГБ оперативки** (лучше 16), **~12 ГБ** свободного места.
- [TLauncher](https://tlauncher.org) — официальный сайт, устанавливается за минуту.
- Наш готовый архив: **[TFG-Modern-0.13.17-TLauncher.zip (705 МБ)](https://github.com/Illusivecup/terrafirmagreg_modern_ru/releases/download/client-0.13.17/TFG-Modern-0.13.17-TLauncher.zip)** — внутри уже ВСЁ: 268 модов, конфиги, шейдеры, 11 ресурспаков, русский язык.

## 1. Шаг 1 — TLauncher и Forge (один раз)

1. Установи и запусти TLauncher.
2. Внизу окна, в списке версий, выбери **`1.20.1-forge-47.4.13`** (если в списке нет — ближайший `1.20.1-forge-47.4.x`). Нажми **«Установить»** и дождись окончания.
3. Запусти игру этой версией **один раз**, дойди до главного меню и закрой игру — создадутся нужные папки.
4. В поле ника введи свой будущий игровой ник (лучше латиницей) и запомни его точь-в-точь — он понадобится для вайтлиста.

## 2. Шаг 2 — скачай архив сборки

Скачай **[TFG-Modern-0.13.17-TLauncher.zip](https://github.com/Illusivecup/terrafirmagreg_modern_ru/releases/download/client-0.13.17/TFG-Modern-0.13.17-TLauncher.zip)** (705 МБ). Внутри архива:

- папка `.minecraft` — вся сборка целиком;
- `README.txt` — короткая памятка по установке (дублирует эту инструкцию).

## 3. Шаг 3 — распаковка (2 минуты)

1. Нажми **Win+R**, введи `%appdata%`, нажми Enter — откроется папка с данными программ.
2. Перетащи папку **`.minecraft`** из архива в это окно и согласись на **замену файлов** (если Windows спросит — «Заменить» / «Да» везде).
3. Готово. Моды, конфиги, шейдеры и русский язык уже внутри.

> Если хочешь сохранить старые миры/настройки от другой игры — они не пострадают: заменяется только то, что совпадает с новой сборкой.

## 4. Шаг 4 — выдели память

В TLauncher: **«Настройки» → вкладка «Дополнительно» → поле «Память»**:

- у тебя 8 ГБ ОЗУ → поставь **6144 МБ**;
- у тебя 16 ГБ ОЗУ и больше → поставь **8192 МБ**.

Больше 8 ГБ ставить **не нужно** — будет только хуже.

## 5. Шаг 5 — вход на сервер

1. В TLauncher выбери версию `1.20.1-forge-47.4.13`, введи ник, жми «Войти в игру».
2. **Первый запуск долгий (5–10 минут)** — грузятся 268 модов. Чёрное окно и «не отвечает» в начале — это нормально, жди.
3. **Отправь админу свой ник точно-точно** — он добавит тебя командой `whitelist add Ник`. Без вайтлиста сервер не пустит.
4. Адрес сервера спроси у админа. В игре: «Сетевая игра» → «Добавить сервер» → вставь адрес (вида `123.45.67.89:25565`) → «Готово» → двойной клик по серверу.

## 6. Шейдеры — уже внутри

| Пакет | Что это |
|---|---|
| **TerraFirmaGreg-Shaders-Complementary 3.1.6** | Фирменная настройка под TFG — включай её |
| **Complementary Unbound r5.9.3** | Классика, чуть светлее картинка |

Включение: в игре **Настройки → Графика → «Пакеты шейдеров»** → выбери пакет → **«Применить»**. На слабом ПК играй без шейдеров или снизь их качество в настройках пакета.

## 8. Частые проблемы

- **«Не пускает на сервер»** — ник не в вайтлисте. Напиши админу ровно тот ник, под которым входишь (регистр важен).
- **«Несовпадение модов» при входе** — скопировал не всё. Повтори Шаг 3 внимательно: в `%appdata%\.minecraft` должны появиться папки `mods`, `config`, `kubejs` и др. из архива.
- **Вылет с «Out of memory»** — подними память (Шаг 4).
- **Долго висит чёрный экран** — первый запуск грузит 268 модов, жди 5–10 минут.
- **Хочу добавить свой мод** — нельзя: сервер требует точное совпадение списка модов.
- **Нет Forge 47.4.13 в списке версий** — ищи именно `1.20.1-forge-47.4.13`; если отсутствует, возьми ближайший `47.4.x` и сообщи админу.
- **Мир грузится вечность после входа** — первые минуты прогружаются чанки TFC, через 5–10 минут станет плавно.
