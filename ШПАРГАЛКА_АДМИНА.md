# Шпаргалка админа — TFG Modern 0.13.17

> Полная документация — в [README.md](README.md). Здесь только быстрые команды.
> Подключение: `ssh root@IP_СЕРВЕРА`. Сервер живёт в `/opt/tfg`, бэкапы — в `/opt/tfg-backups`.

---

## 1. Повседневное управление сервером

```bash
systemctl status tfg-server        # статус (active (running) = всё хорошо)
systemctl start tfg-server         # запустить
systemctl stop tfg-server          # остановить (корректно, с сохранением мира)
systemctl restart tfg-server       # перезапустить
journalctl -u tfg-server -f        # живой лог (Ctrl+C — выйти)
journalctl -u tfg-server -n 100    # последние 100 строк лога
screen -r tfg                      # консоль сервера (выход: Ctrl+A, потом D)
tail -f /opt/tfg/logs/latest.log   # лог файлом
```

## 2. Консоль сервера, не открывая screen

```bash
cd /opt/tfg
./cmd.sh "say Всем привет!"              # сообщение всем в чат
./cmd.sh "list"                          # кто онлайн
./cmd.sh "whitelist add НикДруга"        # добавить в вайтлист
./cmd.sh "whitelist remove Ник"          # убрать из вайтлиста
./cmd.sh "op ТвойНик"                    # выдать админку
./cmd.sh "kick Ник"                      # кикнуть
./cmd.sh "ban Ник"                       # забанить
./cmd.sh "pardon Ник"                    # разбанить
./cmd.sh "save-all"                      # сохранить мир
./cmd.sh "forge tps"                     # TPS сервера (норма 19-20)
```

## 3. Ночной рестарт

Автоматически **каждый день в 05:00** (крон `/etc/cron.d/tfg-night-restart`): предупреждает игроков за 5/2/0.5 минуты, делает свежий бэкап и перезапускает сервер.

```bash
sudo bash /opt/tfg/night-restart.sh            # запустить прямо сейчас
WARN_MIN=10 sudo bash /opt/tfg/night-restart.sh  # с предупреждением за 10 минут
```

Поменять время: отредактируй `/etc/cron.d/tfg-night-restart` (`0 5 * * *` = в 05:00; формат: минута час * * *), затем ничего перезапускать не нужно — cron подхватит сам. Отключить: удали файл `/etc/cron.d/tfg-night-restart`.

## 4. Бэкапы и восстановление

Автоматически **каждый день в 04:00** → `/opt/tfg-backups/`, хранится 7 копий. Перед ночным рестартом тоже делается свежий бэкап. Если на диске свободно меньше 15 ГБ, старые бэкапы подчищаются автоматически (диск 128 ГБ — хватит).

```bash
sudo -u minecraft /opt/tfg/backup.sh           # бэкап вручную прямо сейчас
ls -lht /opt/tfg-backups/                      # список бэкапов

sudo bash /opt/tfg/restore-world.sh            # показать список бэкапов и архивов
sudo bash /opt/tfg/restore-world.sh latest     # откатить мир на самый свежий бэкап
sudo bash /opt/tfg/restore-world.sh /путь/к/файлу.zip   # развернуть любой архив (zip/tar.gz)
```

**Скачать бэкап на свой ПК (обязательно делай это хотя бы раз в неделю!)**

```powershell
# PowerShell на Windows (или WinSCP — мышкой):
scp root@IP_СЕРВЕРА:/opt/tfg-backups/tfg-*.tar.gz D:\tfg-backups\
```

**Залить мир от друга** (он хостил у себя — пошагово в [ПЕРЕЕЗД_НА_НОВЫЙ_СЕРВЕР.md](ПЕРЕЕЗД_НА_НОВЫЙ_СЕРВЕР.md)):

```powershell
# у себя на ПК (WinSCP или scp): залить архив мира в /opt/tfg-backups/
scp D:\Downloads\mir.zip root@IP_СЕРВЕРА:/opt/tfg-backups/
```

```bash
# на сервере: скрипт сам найдёт папку мира внутри zip (по level.dat)
sudo bash /opt/tfg/restore-world.sh /opt/tfg-backups/mir.zip
```

## 5. Игроки: вайтлист и админка

Сервер в offline-режиме (TLauncher), вайтлист **включён принудительно** — на сервер сможет зайти только тот, кого добавили:

```bash
cd /opt/tfg
./cmd.sh "whitelist add Ник"     # добавить каждого друга (ник как в игре, регистр важен)
./cmd.sh "op Ник"                # админка (доступ ко всем командам из п.6)
```

## 6. Внутриигровые команды (в чате игры, нужны права op)

```
/gamemode creative Ник     # креатив (spectator — наблюдатель, survival — выживание)
/time set day              # утро (night — ночь, noon — полдень)
/weather clear             # убрать дождь
/tp Ник1 Ник2              # телепорт к игроку
/kill Ник                  # убить застрявшего игрока (при чище: /kill @e[type=item] — убрать предметы)
/forge tps                 # TPS по измерениям
/spark tps                 # то же, если есть spark
/sethome, /home, /back     # мод FTB Essentials (доступно всем)
/tpa Ник, /rtp, /spawn     # запрос телепорта, рандомная точка, спавн
```

## 7. Здоровье сервера

```bash
free -h                    # память (available — сколько свободно)
df -h                      # место на диске (мир растёт!)
htop                       # нагрузка CPU (выйти: F10)
sudo /opt/tfg/cmd.sh "forge tps"   # TPS: 20 = идеально, <15 = лагает
swapon --show              # работает ли swap (должно быть 6G)
```

Если лагает:
1. Проверь, что RAM сервера на 2 ГБ меньше памяти VPS (п.8).
2. Снизь дальность прорисовки: в `/opt/tfg/server.properties` поставь `view-distance=7`, затем `systemctl restart tfg-server`.
3. Посмотри в логе, какой мод ругается: `journalctl -u tfg-server -n 200 | grep -i error`.

## 8. Сменить память сервера (RAM)

```bash
nano /etc/systemd/system/tfg-server.service    # строка Environment=RAM=8G → 12G
systemctl daemon-reload && systemctl restart tfg-server
```

Правило: отдавать серверу на 2 ГБ меньше, чем всего на VPS (16 ГБ VPS → RAM=12G; 12 ГБ VPS → RAM=8G).

## 9. Хостинг и смены сервера

> **Сейчас у нас месячный тариф (~1700 ₽/мес, 128 ГБ диска)** — машина работает 24/7, платим фикс. Как на него переехали и как переносить мир — в [ПЕРЕЕЗД_НА_НОВЫЙ_СЕРВЕР.md](ПЕРЕЕЗД_НА_НОВЫЙ_СЕРВЕР.md).

- Если когда-нибудь вернёшься на почасовой: не играете неделю — **останови/удали ВМ в панели хостинга** (у Timeweb/Aeza/Selectel остановленная машина продолжает тарифицироваться — тогда только удаление; у Yandex Cloud остановка не тарифицируется).
- **Перед удалением ВМ обязательно** скачай бэкап мира на ПК (п.4) — с удалением машины удаляется и диск.
- Новый VPS снова поднимается за 10 минут тремя командами:

```bash
ssh root@НОВЫЙ_IP
apt update && apt install -y git
git clone https://github.com/Illusivecup/terrafirmagreg_modern_ru.git /opt/tfg-install && cd /opt/tfg-install && RAM=8G bash install.sh
```

## 10. Если сервер упал / что-то сломалось

```bash
systemctl status tfg-server             # 1. смотрим, что говорит systemd
journalctl -u tfg-server -n 50          # 2. последние строки лога — причина обычно в конце
systemctl start tfg-server              # 3. пробуем просто запустить
sudo bash /opt/tfg/restore-world.sh latest   # 4. если мир побился — откат на бэкап
```

Мир побит, бэкапы не помогли, сервер не стартует — смотри полный разбор в [README.md](README.md), разделы «Управление», «Бэкапы», FAQ.
